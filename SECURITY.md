# Security Policy

## Supported Versions

InkIsle is pre-1.0 software. Security fixes are applied to the latest published version when practical.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Report security concerns through GitHub's private vulnerability reporting for this repository, or contact the maintainers through the repository owner if private reporting is unavailable.

Include:

- A description of the issue and affected versions.
- Steps to reproduce or a proof of concept.
- The impact and any known mitigations.

We will acknowledge valid reports as soon as practical and coordinate fixes before public disclosure.
