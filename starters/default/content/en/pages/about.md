---
title: "About InkIsle"
summary: "InkIsle is an AI-native Markdown publishing system."
---

InkIsle is a product layer on top of Astro and Vite.

It does not rebuild a full web framework. It focuses on the Markdown content model, static output, default theme, CLI workflow, and AI-friendly artifacts.

The first milestone is replacing the existing Hexo personal blog and validating the product boundary through a real migration.
