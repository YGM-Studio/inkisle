InkIsle is a static-first Markdown publishing system. The default project only exposes `content/`, so you can focus on writing without learning the Astro project structure.

## Content convention

Main-language content lives directly in `content/posts/` and `content/pages/`. Translated content uses language-prefixed directories such as `content/en/posts/`.

## Next step

Add more Markdown posts, or create `inkisle.config.mjs` when you need to configure site identity, theme, and navigation.
