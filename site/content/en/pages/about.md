---
title: "About InkIsle"
summary: "InkIsle is a Markdown publishing system for static blogs, docs, and content sites."
---

InkIsle is maintained by YGM Studio. It wraps Astro's static rendering foundation in a smaller publishing experience where authors mostly work with Markdown content and light configuration.

## Who it is for

- People moving from older blog frameworks to modern static output.
- Content sites that need RSS, JSON Feed, search indexes, and `llms.txt`.
- Teams that want personal blogs, product blogs, or docs to share one Markdown content model.
