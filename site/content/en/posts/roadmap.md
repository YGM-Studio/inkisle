InkIsle is still alpha software. The current priority is a solid Markdown publishing workflow, not a full CMS.

## Near-term focus

- Stabilize the content-only project shape.
- Improve static deployment on GitHub Pages, Cloudflare Pages, and similar hosts.
- Refine the built-in `personal` and `business-blog` themes.
- Improve machine-friendly outputs such as search indexes, RSS, JSON Feed, and `llms.txt`.
- Clarify theme extension and full project workflows for advanced users.

## Non-goals

InkIsle is not trying to become a server runtime, login system, hosted comment service, or admin backend. It stays static-first, with Markdown as the source of truth.
